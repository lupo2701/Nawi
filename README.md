# NaWi – unsere Klassen-App

Lern-App für den NaWi-Unterricht: Pinnwand, Fakt der Woche, Lern-Check mit Serie, Termine mit Countdown, Lern-Timer und Quiz.

**App öffnen:** https://lupo2701.github.io/Nawi/

## Auf dem iPad / iPhone installieren
1. Link oben in **Safari** öffnen
2. Teilen-Symbol (□↑) → **„Zum Home-Bildschirm“**
3. Fertig – NaWi startet wie eine App im Vollbild

## Inhalte ändern
In `index.html` ganz oben im `<script>`-Teil: `KLASSE`, `LEHRER`, `PINNWAND`, `FESTE_TERMINE`, `FAKTEN`, `QUIZ`.
